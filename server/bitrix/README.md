# Один чек на один платёж и отключение дублирующего сообщения Bitrix

Файл `luzhniki-fine-check-notification.php` подключается на сервере Битрикса к
событию `sale:OnPrintableCheckSend`.

Он срабатывает только для заказов, корзина которых содержит `XML_ID`,
начинающийся с `fine-`, и для платёжной системы ID 24. Перед переводом оплаты в
`PAID=Y` обработчик берёт именованную блокировку MySQL по ID платежа и повторно
читает его состояние из базы. Если другой callback уже подтвердил эту оплату,
повторный переход и постановка второго фискального чека в очередь подавляются.
Блокировка снимается после сохранения заказа; при аварийном завершении её
автоматически освобождает соединение с БД.

Для таких же заказов отключается стандартное письмо/СМС Битрикса со ссылкой на
чек. Формирование единственного чека, его фискализация и отправка Платформой ОФД
не меняются. Другие заказы интернет-магазина не затрагиваются.

Обработчик не отправляет собственных сообщений. Фискальный чек отправляет
Платформа ОФД на email, записанный в свойства заказа. REST API подтверждает
правильность email в заказе, но не может подтвердить фактическую доставку письма.

Эти файлы запускаются отдельно на сервере Bitrix `aqua-bitrix-srv01`. Установка
сайта на веб-сервере сама по себе обработчик не подключает.

```bash
cd server/bitrix
bash 00-check-read-only.sh
bash 01-install-handler.sh
bash 02-status-read-only.sh
```

Первая и третья команды ничего не изменяют. Установщик создаёт резервные копии,
проверяет PHP-синтаксис и атомарно добавляет в `local/php_interface/init.php`
маркированный блок `require_once`. Повторный запуск безопасен и не регистрирует
обработчик второй раз.

Это не изменение ядра Bitrix и не замена файлов сайта штрафов. На сервер Bitrix
добавляется один файл в `local/php_interface/include`, а в существующий
`local/php_interface/init.php` — один маркированный `require_once`.

Для отключения с сохранением файлов:

```bash
bash 03-disable-handler.sh
```

Скрипт удаляет только свой маркированный блок из `init.php`, а файл обработчика
переименовывает с суффиксом `.disabled.ДАТА`. Остальной `init.php` не меняется.
